# Scale Media Website

Premium animated digital marketing agency website built with Next.js.

## Run locally
npm install
npm run dev

## Production
npm run build
npm start

## Vercel
Import this project into Vercel. No special configuration is required.

## Replace logo
Put your actual logo at `public/logo.png` and update the brand component in `app/page.tsx` to use an image if desired.

## Edit business details
Update services, stats, testimonials, case studies and contact details near the top of `app/page.tsx`.
